# Anand's 45th Birthday Tribute 🎂

A web tribute to **Anand** from **The Beatles** — four friends, one WhatsApp group,
twelve years (2014–2026), and everything beautiful found in ~20,000 messages.

👉 The site lives in [`site/`](./site/). See [`site/README.md`](./site/README.md)
for how to view, publish, and edit it.

Every quote is verbatim from the group chat and dated. Built to be deployed free on
GitHub Pages — and to grow once the photos arrive.
